# 前端鉴权变更说明

本文档记录最近在前端为项目添加的鉴权与路由保护相关更改，以及如何验证与运行相关说明。

## 目标
- 在前端实现受保护路由（ProtectedRoute）和集中化鉴权状态（AuthContext），使未登录用户被重定向到登录页。

## 主要更改文件
- `package.json`：新增依赖 `react-router-dom`。
- `src/App.jsx`：集成 `react-router-dom` 路由，新增 `/login` 路由，并使用 `AuthProvider` 包裹应用。
- `src/components/ProtectedRoute.jsx`：受保护路由组件，消费 `AuthContext` 判定登录状态并在未登录时跳转到 `/login`。
- `src/pages/LoginPage.jsx`：最小登录页面，使用 `AuthContext.login` 发起登录请求（`credentials: 'include'`）。
- `src/context/AuthContext.jsx`：`AuthProvider` 实现，应用启动时会请求 `GET /api/auth/me` 获取当前用户信息，并提供 `login`、`logout`、`refresh` 方法。

## 后端相关提醒
- 后端鉴权接口位于 `backend/src/routes/auth.js`：`/api/auth/register`、`/api/auth/login`、`/api/auth/logout`、`/api/auth/me`。
- 后端使用 httpOnly cookie 保存 JWT（前端无法直接读取 token），前端通过 `GET /api/auth/me` 获取用户信息。

## 如何本地验证（快速步骤）
1. 启动后端（位于 `backend`）：
```bash
cd backend
npm install
npm run dev
```
后端默认监听 `http://localhost:4000`。

2. 启动前端：
```bash
cd d:/code/webstorm_code/webtool_for_ai/ProjectPreBuilder
npm install
npm run dev
```
前端默认监听 `http://localhost:5173`。

3. 访问：打开 `http://localhost:5173/`。若未登录将被重定向到 `http://localhost:5173/login`。

4. 示例账号（调试用）：
- 用户名：`admin`
- 密码：`123456` （已为你重置；生产环境请立即更改）

5. 命令行登录示例（调试）：
```bash
curl.exe -i -c cookies.txt -X POST "http://localhost:4000/api/auth/login" \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"admin\",\"password\":\"123456\"}"

curl.exe -i -b cookies.txt "http://localhost:4000/api/auth/me"
```

## UX 注意与改进点
- 当前 `ProtectedRoute` 在 `AuthContext.loading` 为 `true` 时返回 `null`（页面为空白）。若需要更友好的体验，可将其改为显示加载指示器或更明确的登录提示；我可以替你改进。
- 若后端运行在不同地址，请在前端根目录设置 `VITE_API_BASE` 环境变量（例如 `VITE_API_BASE=http://你的后端地址:4000`）。
