## 3. 导出门禁策略落地

- `ERROR > 0`：阻断导出（已实现）。
- `ERROR = 0 && WARN > 0`：弹窗二次确认后允许导出（已实现）。
- 仅 `INFO`：直接导出（已实现）。

## 5. 后续建议

1. 将 `FILE_TYPE_REGISTRY` 抽离到独立常量文件，与 UI 侧共用，避免双端不一致。
2. 增加自动化单测，按 Rule ID 构造最小输入样例做回归验证。
3. 若需兼容历史导入格式（仅 `relations` 无 `dependencies`），可在导入模式放宽 PBV-002。
