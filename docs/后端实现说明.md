# 后端实现说明

## 概要

本项目后端为最小认证服务（位于 `backend/`），提供基于用户名/密码的注册、登录、登出和当前用户查询。采用 Node.js + Express + SQLite（使用 `better-sqlite3`）实现，登录采用 JWT（通过 httpOnly cookie 返回给前端）。

## 目录结构（关键文件）

- `backend/package.json`：后端依赖与启动脚本
- `backend/src/server.js`：Express 应用入口，CORS 与路由挂载
- `backend/src/routes/auth.js`：实现 `register`、`login`、`logout`、`me` 接口
- `backend/src/middleware/auth.js`：JWT 校验中间件与角色守卫
- `backend/src/db.js`：SQLite 访问封装（基于 `better-sqlite3`）
- `backend/migrations/001_create_users.sql`：用户表创建脚本（SQLite）
- `backend/.env.example`：环境变量样例

## 环境变量（`backend/.env`）

至少设置：

```
DB_PATH=./data/auth.db
JWT_SECRET=replace_with_strong_secret
JWT_EXPIRES_IN=2h
COOKIE_NAME=auth_token
NODE_ENV=development
FRONTEND_ORIGIN=http://localhost:5173
PORT=4000
```

- `JWT_SECRET` 必须设置为强随机字符串，否则登录/签名失败。

## 数据库迁移（SQLite）

- 已提供脚本：`backend/migrations/001_create_users.sql`。
- 快速应用方式（项目根或 backend 目录）：

PowerShell（在 `backend` 目录）：
```powershell
# 若安装 sqlite3
Get-Content .\migrations\001_create_users.sql | sqlite3 .\data\auth.db
```

或使用已安装的 Node 与依赖（不依赖系统 sqlite3）：
```powershell
cd backend
npm install
node -e "const fs=require('fs');const Database=require('better-sqlite3');fs.mkdirSync('./data',{recursive:true});const db=new Database('./data/auth.db');const sql=fs.readFileSync('./migrations/001_create_users.sql','utf8');db.exec(sql);db.close();console.log('migrations applied')"
```

## 运行服务

```bash
cd backend
npm install
npm run dev
```

默认监听 `PORT`（`.env` 中配置），示例为 `4000`。

## API（简要）

- `POST /api/auth/register`
  - Body: `{ "username": "u", "password": "p", "role": "viewer|editor|admin" }`
  - 201: 返回创建的用户（不含密码）

- `POST /api/auth/login`
  - Body: `{ "username": "u", "password": "p" }`
  - 200: 返回用户信息并在 httpOnly cookie 中设置 JWT

- `POST /api/auth/logout`
  - 清除 cookie，返回 200

- `GET /api/auth/me`
  - 需要认证（cookie），返回当前用户信息

## 前端 / 手动测试示例

PowerShell 示例（保存会话）：
```powershell
# 注册
Invoke-WebRequest -Method Post -Uri "http://localhost:4000/api/auth/register" -ContentType "application/json" -Body '{"username":"admin","password":"123456","role":"admin"}'

# 登录并保存会话
Invoke-WebRequest -Method Post -Uri "http://localhost:4000/api/auth/login" -ContentType "application/json" -Body '{"username":"admin","password":"123456"}' -SessionVariable sess

# 查询当前用户
Invoke-WebRequest -Method Get -Uri "http://localhost:4000/api/auth/me" -WebSession $sess

# 登出
Invoke-WebRequest -Method Post -Uri "http://localhost:4000/api/auth/logout" -WebSession $sess
```

curl（在类 Unix 或 Windows 下的 `curl.exe`）：
```bash
curl.exe -i -X POST "http://localhost:4000/api/auth/register" -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"123456\",\"role\":\"admin\"}"
```

> 注意：PowerShell 的 `curl` 是别名，请使用 `curl.exe` 或 `Invoke-WebRequest`。

## 验证数据库内容

在 `backend` 目录，你可以用 Node 快速查看：
```bash
node -e "const Database=require('better-sqlite3');const db=new Database('./data/auth.db');console.log(db.prepare('select id, username, role, created_at from users').all());db.close();"
```

或使用 `sqlite3` CLI：
```bash
sqlite3 backend/data/auth.db
sqlite> .tables
sqlite> select id, username, role, created_at from users;
```
