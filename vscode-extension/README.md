# ProjectPreBuilder VS Code Extension

This folder contains a minimal VS Code extension skeleton that opens the current ProjectPreBuilder web app in a VS Code webview.

## How to run
1. Open this folder in VS Code.
2. Press F5 to launch the Extension Development Host.
3. Run the command `Open ProjectPreBuilder`.

## Notes
- The webview loads the built app from the project `dist/` folder.
- The extension already includes a simple `exportToWorkspace` message handler for future export-to-workspace actions.
